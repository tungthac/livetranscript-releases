# liveTranscript: bản cài đặt

Repo này chỉ chứa bản cài đặt của app liveTranscript (không có mã nguồn).

- **Cài lần đầu**: vào mục [Releases](../../releases/latest), tải file `.dmg` (macOS, Apple Silicon) hoặc `.exe` (Windows).
- **Cập nhật**: app đã cài tự kiểm tra và tải bản mới từ đây; khi tải xong, bấm **Cài bản …** trên thanh tiêu đề của app.
- **Kích hoạt**: app cần mã kích hoạt do người phát hành cấp.
